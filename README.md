## About This Repository

This repository documents my hands-on cybersecurity learning journey through
[TryHackMe](https://tryhackme.com/).

It contains structured learning notes, practical labs, technical exercises,
and selected penetration-testing writeups.

### Current Focus

- Penetration Testing
- Web Application Security
- Network Security
- Vulnerability Assessment
- Exploitation
- Privilege Escalation
- Active Directory Security
- Security Operations
- Security Engineering

### Learning Areas

| Area | Focus |
|---|---|
| Foundations | Cybersecurity fundamentals, networking, Linux, Windows, cryptography |
| Offensive Security | Reconnaissance, exploitation, web security, privilege escalation |
| Defensive Security | SOC, SIEM, threat detection, incident response |
| Security Engineering | Hardening, vulnerability management, DevSecOps |
| AI Security | AI security, LLM security, prompt injection, AI threats |
