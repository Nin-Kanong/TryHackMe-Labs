## About

This repository documents my hands-on cybersecurity learning journey
through TryHackMe labs and practical security exercises.

The goal is to build practical skills in:

- Penetration Testing
- Vulnerability Assessment
- Web Application Security
- Network Security
- Defensive Security
- Security Analysis
- Security Engineering
- Security Automation
- AI Security

Each lab is documented with the techniques, tools, concepts, and
lessons learned during the exercise.

---

## Learning Areas

| Area | Focus |
|---|---|
| Offensive Security | Reconnaissance, Enumeration, Exploitation, Post-Exploitation |
| Web Security | SQL Injection, XSS, Authentication, Web Enumeration |
| Defensive Security | Security Monitoring, Detection, Incident Analysis |
| Security Analysis | Log Analysis, Threat Analysis, Investigation |
| Security Engineering | Network Security, System Security, Security Tools |
| AI Security | AI Security Concepts and Security Research |
| Foundations | Networking, Linux, Windows, Security Fundamentals |
