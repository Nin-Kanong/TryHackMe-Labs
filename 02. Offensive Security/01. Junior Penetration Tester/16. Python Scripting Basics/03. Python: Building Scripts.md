## Task 2: Functions

A **function** is a reusable block of code that performs a specific task. It helps avoid repeating the same code.

Think of a vending machine:
- **Call**: Press a button to start.
- **Arguments**: Input, such as money or a selection.
- **Return value**: The result, such as a drink.

---


### Defining a Function


Use the `def` keyword to create a function in Python.

```py
def greet(name):
    print(f"Hello, {name}. Welcome to the system.")
```

How it works:

- `def` defines the function.
- `greet` is the function name.
- `name` is a parameter (input).
- The indented code is the function body.

Call the function with different arguments:

```
greet("Alice")    # Hello, Alice. Welcome to the system.
greet("Bob")      # Hello, Bob. Welcome to the system.
```

> Define a function once and reuse it by calling it whenever needed.


---


### Parameters vs. Arguments

- **Parameter**: The variable in the function definition.
- **Argument**: The actual value passed to the function when it is called.

> Parameters are placeholders; arguments are the actual values you provide.



### Return Values

The ``return`` keyword sends a result back to the code that called the function.

````py
def check_length(password, min_length):
    if len(password) >= min_length:
        return True
    else:
        return False

result = check_length("Tr0ub4dor", 8)
print(result)   # True
````

- return sends a value back to the caller.
- It immediately ends the function.
- A function without ``return`` returns None by ``default``.

### Multiple Parameters

A **function** can accept multiple inputs, separated by commas.

```py
def score_password(password, common_list):
    score = 0

    if len(password) >= 8:
        score += 1
    if len(password) >= 12:
        score += 1
    if any(c.isdigit() for c in password):
        score += 1
    if any(c.isupper() for c in password):
        score += 1
    if password not in common_list:
        score += 1

    return score
```

How it works:

- `password`: The password to evaluate.
- `common_list`: A list of common weak passwords.
- `score`: Increases when the password meets each criterion.
- `return score`: Sends the final score back to the caller.

The function returns a score from `0` to `5`.

---


### Default Parameter Values

A **default parameter** value is used when the caller does not provide an argument.

```py
def check_length(password, min_length=8):
    return len(password) >= min_length

print(check_length("short"))          # False   (uses default min_length of 8)
print(check_length("short", 4))       # True    (overrides default with 4)
```

### Scope

**Scope** determines where a variable can be accessed.
````py
def calculate():
    result = 42     # local variable
    return result

calculate()

````

## Task 3: Error Handling

If a user enters `"abc"` when a number is expected, `int("abc")` raises a `ValueError` and the program crashes unless the error is handled.

Use `try` and `except` to handle the error gracefully:

- `try`: Runs code that might cause an error.
- `except`: Handles the error instead of crashing.

---


### The Problem

Consider this short script:
````py
text = input("Enter a number: ")   # user types "hello"
number = int(text)                  # CRASH: ValueError
print(f"You entered {number}")
````

Python raises a `ValueError` at `int(text)` because `"hello"` cannot be converted to an integer.


An example of running this script could be:
````       
Enter a number: hello
Traceback (most recent call last):
  File "demo.py", line 2, in <module>
    number = int(text)
ValueError: invalid literal for int() with base 10: 'hello'
````
        

### The try/except Block

Use `try` and `except` to handle errors without crashing your program.

```py
try:
    text = input("Enter a number: ")
    number = int(text)
    print(f"You entered {number}")
except ValueError:
    print("That is not a valid number. Please try again.")
```

<img width="1532" height="216" alt="image" src="https://github.com/user-attachments/assets/4664d904-c98e-412f-897d-136a7b57da10" />


How it works:

- `try`: Runs code that might cause an error.
- `except ValueError`: Handles invalid number input.
- If an error occurs, Python runs the `except` block instead of crashing.

If the user enters `hello`, the program displays a helpful error message. If they enter `42`, it prints `You entered 42`.

---


### Common Exception Types

| Exception           | When it occurs             | Example               |
| ------------------- | -------------------------- | --------------------- |
| `ValueError`        | Invalid value conversion   | `int("abc")`          |
| `FileNotFoundError` | File does not exist        | `open("missing.txt")` |
| `ZeroDivisionError` | Dividing by zero           | `10 / 0`              |
| `KeyError`          | Dictionary key is missing  | `d["missing_key"]`    |
| `IndexError`        | List index is out of range | `mylist[99]`          |

---


### Catching Multiple Exceptions

We can handle different errors differently:
````py
try:
    filename = input("File to open: ")
    with open(filename) as f:
        data = f.read()
    port = int(data.strip())
except FileNotFoundError:
    print(f"Error: '{filename}' does not exist.")
except ValueError:
    print(f"Error: the file does not contain a valid number.")
````

### The Generic except

Using ``except Exception as e`` catches most exceptions. Use it sparingly, as it can hide bugs you would want to know about:

````py
try:
    risky_operation()
except Exception as e:
    print(f"Something went wrong: {e}")

````

The ``as e`` part stores the exception's message in the variable ``e``, which you can print for debugging.



### Combining Error Handling with Loops
A common and powerful pattern is to wrap user input in a loop so the program keeps asking until valid input is provided:

````py
while True:
    try:
        age = int(input("Enter your age: "))
        break   # valid input received; exit the loop
    except ValueError:
        print("Invalid input. Please enter a whole number.")
````

## Task 4: Reading and Writing Files

In cybersecurity, Python files are useful for:

- **Reading** wordlists and log files.
- **Analyzing** suspicious activity in logs.
- **Writing** scan results to reports.


### Reading a File

The `open()` function opens a file using a specified mode:

````py
f = open("passwords.txt", "r")
content = f.read()
print(content)
f.close()
````

| Mode  | Purpose                                       |
| ----- | --------------------------------------------- |
| `"r"` | Read a file                                   |
| `"w"` | Write to a file (overwrites existing content) |
| `"a"` | Append to a file                              |


---


### The with Statement (Context Managers)

Use `with open()` to safely handle files. Python automatically closes the file when the block ends, even if an error occurs.

```py
with open("passwords.txt", "r") as f:
    content = f.read()

print(content)   # the file is already closed at this point
```

- `with` manages the file automatically.
- `"r"` opens the file for reading.
- `f.read()` reads its contents.
- The file closes automatically when the indented block ends.
