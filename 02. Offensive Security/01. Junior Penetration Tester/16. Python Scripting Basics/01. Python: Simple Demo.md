This task teaches us how to compare the user's guess with the secret number using conditional statements.

#### Understanding the conditions
- **Out of range**: If the guess is less than 1 or greater than 20, display Out of range.
- **Too low**: If the guess is smaller than the secret number, display Too low.
- **Too high**: If the guess is greater than the secret number, display Too high.
- **Correct**: If none of the above conditions are true, display You got it.


Python concepts:

| Concept | Meaning                                      |
| ------- | -------------------------------------------- |
| `if`    | Checks the first condition.                  |
| `elif`  | Checks another condition.                    |
| `else`  | Runs when all previous conditions are false. |
| `or`    | True when at least one condition is true.    |
| `<`     | Less than.                                   |
| `>`     | Greater than.                                |


Python code:
````py
# Give a hint using if / elif / else.
if guess < 1 or guess > 20:
    print("That number is out of range. Try again.")
elif guess < secret:
    print("Too low, try again.")
elif guess > secret:
    print("Too high, try again.")
else:
    print("You got it in", tries, "tries!")
````

The program checks the user's guess against the computer's ``secret`` number.

There are 4 possible situations:
- **Out of range**: Guess is smaller than 1 or greater than 20.
- **Too low**: Guess is smaller than the secret number.
- **Too high**: Guess is greater than the secret number.
- **Correct**: Guess matches the secret number.

> The computer checks the guess and tells the user whether the number is out of range, too low, too high, or correct.

## Task 4: Iterations

A **Loop** allows Python to repeat the same code multiple time until a condition is met.


#### What is a loop?
Examples in daily life:
- **Shopping**: Visit different shops until you find the right T-shirt.
- **Parking**: Search different rows until you find an empty parking space.

We use a while loop:
````py
while guess != secret:
````

- ``while`` – Repeats the code as long as the condition is true.
- ``guess`` – The number entered by the user.
- ``!=`` – Means "not equal to".
- ``secret`` – The computer's secret number.

> A ``while`` loop allows users to guess repeatedly until they find the correct number.


Python has 2 main types of loops:

| Loop         | Meaning                                                    | Example                  |
| ------------ | ---------------------------------------------------------- | ------------------------ |
| `for` loop   | Repeats code for each item or a specified number of times. | `for i in range(5):`     |
| `while` loop | Repeats code while a condition is true.                    | `while guess != secret:` |

##### For Loop

Used when we want to repeat something a specific number of times or go through a collection.

```
for i in range(5):    print("Hello")
```


##### While Loop

Used when we want to repeat something until a condition changes.

```
while guess != secret:    print("Try again")
```






Let’s paste the code from Task 3 in the body of our ``while`` loop.


In this open file that we was downloaded `guess_v3.py`:
````py
import random  # gives us tools for picking random numbers

# ----------------------------
# Guess the Number (Beginner Demo)
# ----------------------------
# The computer picks a secret number.
# The player keeps guessing until they find it.

secret = random.randint(1, 20)  # a <= secret <= b
tries = 0
guess = 0  # start with a value that cannot be the secret (since secret is 1..20)

print("I'm thinking of a number between 1 and 20")

# Repeat until the user guesses the secret number.
while guess != secret:
    text = input("Take a guess: ")  # input() returns text (a string)
    guess = int(text)  # convert the text to a number
    
    tries = tries + 1  # add 1 try

    # Give a hint using if / elif / else.
    if guess < 1 or guess > 20:
        print("That number is out of range. Try again.")
    elif guess < secret:
        print("Too low, try again.")
    elif guess > secret:
        print("Too high, try again.")
    else:
        print("You got it in", tries, "tries!")
````
