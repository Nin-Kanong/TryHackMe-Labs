### Variables and Data Types

**Variables** store information or values that can be used and changed in a program.

````py
food = "ice cream"   # a string (text)
money = 2000          # an integer (whole number)
````

- ``food``: Stores text (string).
- ``money``: Stores a whole number (integer).



We can change a variable's value:
````
age = 30
age = age + 1
print(age)
````
<img width="1073" height="281" alt="image" src="https://github.com/user-attachments/assets/ce0af47c-9db0-4403-9e0f-c671a54eceeb" />


| Type    | Name    | Meaning                               |
| ------- | ------- | ------------------------------------- |
| `str`   | String  | Text, e.g. `"Hello"`                  |
| `int`   | Integer | Whole numbers, e.g. `42`              |
| `float` | Float   | Decimal numbers, e.g. `3.14`          |
| `bool`  | Boolean | `True` or `False`                     |
| `list`  | List    | Collection of items, e.g. `[1, 2, 3]` |

> Variables store data, and data types describe what kind of data is stored.



We can check a value's type using ``type()``:
````
username = "admin"
port = 8080
print(type(username))   # <class 'str'>
print(type(port))       # <class 'int'>
````

### Conditional Statements and Logical Operators

Conditional statements allow Python to make decisions based on conditions.

````py
age = 18
if age < 17:
    print("You are NOT old enough to drive")
else:
    print("You are old enough to drive")
````

- ``if``: Checks the condition.
- ``elif``: Checks another condition.
- ``else``: Runs when previous conditions are false.
- ``:``: Starts a code block.
- ``Indentation``: Shows which code belongs to the condition.


**Comparison Operators**:

| Operator | Meaning                  |
| -------- | ------------------------ |
| `==`     | Equal to                 |
| `!=`     | Not equal to             |
| `<`      | Less than                |
| `>`      | Greater than             |
| `<=`     | Less than or equal to    |
| `>=`     | Greater than or equal to |

**Logical Operators**:

| Operator | Meaning                                  |
| -------- | ---------------------------------------- |
| `and`    | Both conditions must be true.            |
| `or`     | At least one condition must be true.     |
| `not`    | Reverses True to False or False to True. |


Example:
````py
name = "bob"
hungry = True

if name == "bob" and hungry == True:
    print("Bob is hungry")
elif name == "bob" and not hungry:
    print("Bob is not hungry")
else:
    print("Not sure who this is or if they are hungry")
````

### What's New: Type Conversion and f-strings

#### Type Conversion

Type conversion means changing data from one type to another.


| Function  | Meaning               | Example                  |
| --------- | --------------------- | ------------------------ |
| `int()`   | Convert to integer    | `int("42")` → `42`       |
| `float()` | Convert to decimal    | `float("3.14")` → `3.14` |
| `str()`   | Convert to text       | `str(42)` → `"42"`       |
| `bool()`  | Convert to True/False | `bool(0)` → `False`      |


```py
text = input("Enter a port number: ")    # user types 443
print(type(text))                         # <class 'str'>

port = int(text)                          # convert to integer
print(type(port))                         # <class 'int'>
print(port + 1)                           # 444
```

<img width="1783" height="362" alt="image" src="https://github.com/user-attachments/assets/8b273e6d-5ab6-4d9a-851d-51b2702ce59a" />


- `input()` – Always receives input as a string.
- `type()` – Checks the data type.
- `int()` – Converts text into an integer.
- `port + 1` – Adds 1 to the number.

> Use type conversion to change data types. For example, `int()` converts user input from text into a number so Python can perform mathematical calculations.


#### Formatted Strings (f-strings)

**f-strings** allow us to insert variables directly into text using curly braces ``{}``.

````py
username = "admin"
port = 443

# Old approach (comma-separated, as used in Simple Demo)
print("User", username, "is on port", port)

# Modern approach (f-string)
print(f"User {username} is on port {port}")
````

#### Augmented Assignment Operators

Augmented assignment means using shortcuts to update a variable's value.

````py
count = 0
count += 1    # same as count = count + 1
count -= 1    # same as count = count - 1
count *= 2    # same as count = count * 2
count /= 4    # same as count = count / 4
````


| Operator | Meaning             | Same As             |
| -------- | ------------------- | ------------------- |
| `+=`     | Add and assign      | `count = count + 1` |
| `-=`     | Subtract and assign | `count = count - 1` |
| `*=`     | Multiply and assign | `count = count * 2` |
| `/=`     | Divide and assign   | `count = count / 4` |
