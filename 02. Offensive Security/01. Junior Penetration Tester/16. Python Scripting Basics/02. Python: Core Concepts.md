### Conditional Statements and Logical Operators

Conditional statements allow Python to make decisions based on conditions.

````py
age = 18
if age < 17:
    print("You are NOT old enough to drive")
else:
    print("You are old enough to drive")
````

- ``if``: Checks the condition.
- ``elif``: Checks another condition.
- ``else``: Runs when previous conditions are false.
- ``:``: Starts a code block.
- ``Indentation``: Shows which code belongs to the condition.


**Comparison Operators**:

| Operator | Meaning                  |
| -------- | ------------------------ |
| `==`     | Equal to                 |
| `!=`     | Not equal to             |
| `<`      | Less than                |
| `>`      | Greater than             |
| `<=`     | Less than or equal to    |
| `>=`     | Greater than or equal to |

**Logical Operators**:

| Operator | Meaning                                  |
| -------- | ---------------------------------------- |
| `and`    | Both conditions must be true.            |
| `or`     | At least one condition must be true.     |
| `not`    | Reverses True to False or False to True. |


Example:
````py
name = "bob"
hungry = True

if name == "bob" and hungry == True:
    print("Bob is hungry")
elif name == "bob" and not hungry:
    print("Bob is not hungry")
else:
    print("Not sure who this is or if they are hungry")
````

### What's New: Type Conversion and f-strings

#### Type Conversion

Type conversion means changing data from one type to another.


| Function  | Meaning               | Example                  |
| --------- | --------------------- | ------------------------ |
| `int()`   | Convert to integer    | `int("42")` → `42`       |
| `float()` | Convert to decimal    | `float("3.14")` → `3.14` |
| `str()`   | Convert to text       | `str(42)` → `"42"`       |
| `bool()`  | Convert to True/False | `bool(0)` → `False`      |


```py
text = input("Enter a port number: ")    # user types 443
print(type(text))                         # <class 'str'>

port = int(text)                          # convert to integer
print(type(port))                         # <class 'int'>
print(port + 1)                           # 444
```

- `type()` – Checks the data type.
- `int()` – Converts text into an integer.
- `port + 1` – Adds 1 to the number.

> Use type conversion to change data types. For example, `int()` converts user input from text into a number so Python can perform mathematical calculations.

### String Indexing and Slicing

**Indexing** means accessing individual characters in a string using their positions.

Python indexing starts at ``0``, not ``1``.

```
text = "Python"print(text[0])  # Pprint(text[1])  # yprint(text[2])  # t
```

**Index Table**:

| Index     | 0 | 1 | 2 | 3 | 4 | 5 |
| --------- | - | - | - | - | - | - |
| Character | P | y | t | h | o | n |

- `text[0]` → First character.
- `text[1]` → Second character.
- `text[5]` → Sixth character.

> Python uses indexes starting from `0` to access individual characters in a string.


````py
word = "Python"
print(word[0])     # P   (first character)
print(word[5])     # n   (last character)
print(word[-1])    # n   (negative index counts from the end)
````

<img width="1297" height="455" alt="image" src="https://github.com/user-attachments/assets/bac39446-8b8a-4c07-9799-2431cab7b457" />



**Slicing** means extracting part of a string using its index positions.
````py
word = "Python"
print(word[0:3])   # Pyt   (characters at index 0, 1, 2)
print(word[2:])    # thon  (from index 2 to the end)
print(word[:4])    # Pyth  (from the start to index 3)
````

### Useful String Methods

String methods are built-in functions used to modify, check, and work with text.

| Method          | Meaning                                   | Example                     |
| --------------- | ----------------------------------------- | --------------------------- |
| `.upper()`      | Converts text to uppercase.               | `"hello"` → `"HELLO"`       |
| `.lower()`      | Converts text to lowercase.               | `"HELLO"` → `"hello"`       |
| `.strip()`      | Removes spaces at the beginning and end.  | `" hi "` → `"hi"`           |
| `.replace()`    | Replaces text with other text.            | `"cat"` → `"bat"`           |
| `.split()`      | Splits text into a list.                  | `"a,b,c"` → `["a","b","c"]` |
| `.startswith()` | Checks the beginning of text.             | `"http://"` → `True`        |
| `.endswith()`   | Checks the ending of text.                | `"file.txt"` → `True`       |
| `.count()`      | Counts occurrences of characters or text. | `"banana"` → `3`            |

### Character Checks

Python provides string methods to check whether a character is an uppercase letter, lowercase letter, or number.

| Method       | Meaning                    | Example         |
| ------------ | -------------------------- | --------------- |
| `.isupper()` | Checks uppercase letters.  | `"A"` → `True`  |
| `.islower()` | Checks lowercase letters.  | `"a"` → `True`  |
| `.isdigit()` | Checks numbers (digits).   | `"5"` → `True`  |
| `.isalpha()` | Checks letters only.       | `"A"` → `True`  |
| `.isalnum()` | Checks letters or numbers. | `"A5"` → `True` |

````py
char = "A"
print(char.isupper())    # True
print(char.islower())    # False
print(char.isdigit())    # False
print(char.isalpha())    # True   (is it a letter?)
print(char.isalnum())    # True   (is it a letter or digit?)
````

## Task 4: List and Dictionaries 

Python uses lists and dictionaries to organize multiple data items, such as IP addresses, open ports, and network services.


### Lists

A **list** in Python stores multiple items in one variable, using square brackets ``[]``. Items can be numbers, strings, or different data types.

````py
ports = [22, 80, 443, 8080]
usernames = ["admin", "root", "guest"]
mixed = ["server1", 443, True]
````

#### Accessing and Modifying List Elements

- **Indexing**: Access an item by its position. Indexing starts at 0.
- **Negative indexing**: ``-1`` accesses the last item.
- **Slicing**: Get multiple items using [``start:end``]. The end index is excluded.
- **Modifying**: Change an item by assigning a new value to its index.


````py
ports = [22, 80, 443, 8080]

print(ports[0])    # 22
print(ports[-1])   # 8080
print(ports[1:3])  # [80, 443]

ports[0] = 2222
print(ports)       # [2222, 80, 443, 8080]
````




#### Common List Methods

| Method       | Purpose                               | Example              |
| ------------ | ------------------------------------- | -------------------- |
| `.append(x)` | Adds an item to the end               | `ports.append(3306)` |
| `.remove(x)` | Removes the first matching item       | `ports.remove(80)`   |
| `.pop(i)`    | Removes and returns item at index `i` | `ports.pop(0)`       |
| `.sort()`    | Sorts items in ascending order        | `ports.sort()`       |
| `.reverse()` | Reverses the item order               | `ports.reverse()`    |
| `len(list)`  | Returns the number of items           | `len(ports)`         |

The ``in`` operator, which we introduced with strings, works on lists as well:

````py
common_passwords = ["123456", "password", "admin", "letmein"]

if "password" in common_passwords:
    print("This password is in the common list.")
````



### Dictionaries

A **dictionary** stores data as key-value pairs using curly braces ``{}``.
- **Key**: The item you use to look up data.
- **Value**: The information associated with that key.

````py
services = {
    22: "SSH",
    80: "HTTP",
    443: "HTTPS",
    3306: "MySQL"
}
````


#### Accessing Dictionary Values
We retrieve a value by passing its key inside square brackets:
````py
print(services[22])     # SSH
print(services[443])    # HTTPS
````

    
#### Adding, Updating, and Removing Entries

````py
# Add a new entry
services[8080] = "HTTP-Alt"

# Update an existing entry
services[22] = "OpenSSH"

# Remove an entry
del services[3306]

print(services)
# {22: 'OpenSSH', 80: 'HTTP', 443: 'HTTPS', 8080: 'HTTP-Alt'}
````


#### Checking for Keys
````py
if 22 in services:
    print(f"Port 22 runs {services[22]}")
````





#### Useful Dictionary Methods

| Method               | Purpose                                               | Example                       |
| -------------------- | ----------------------------------------------------- | ----------------------------- |
| `.keys()`            | Returns all keys                                      | `services.keys()`             |
| `.values()`          | Returns all values                                    | `services.values()`           |
| `.items()`           | Returns key-value pairs as tuples                     | `services.items()`            |
| `.get(key, default)` | Returns the value, or a default if the key is missing | `services.get(22, "Unknown")` |

Using ``.get()`` Safely:
- ``services[9999]`` causes a KeyError if the key doesn't exist.
- ``services.get(9999, "Unknown")`` returns ``"Unknown"`` instead of an error.

````py
result = services.get(9999, "Unknown")
print(result)   # Unknown
````

## Task 5: Arithmetic and Membership Operators

Python operators:

- Arithmetic: `+`, `-`, `*`, `/`, `%`
- Comparison: `<`, `>`, `==`, `!=`
- Logical: `and`, `or`, `not`

> These operators help perform calculations, compare values, and combine conditions.


### New Arithmetic Operators

| Operator | Meaning                      | Example  | Result |
| -------- | ---------------------------- | -------- | ------ |
| `**`     | Exponent (power)             | `2 ** 8` | `256`  |
| `//`     | Floor division (rounds down) | `7 // 2` | `3`    |
| `%`      | Modulus (remainder)          | `7 % 2`  | `1`    |

- `%` can check even or odd numbers: `number % 2 == 0` means even.
- `/` returns a decimal: `7 / 2 = 3.5`.
- `//` returns the rounded-down result: `7 // 2 = 3`.

---

### The Membership Operator: in


The ``in`` operator checks whether an item exists in a collection, such as a list or string.


````py
# Checking if a password is in a list of common passwords
common = ["123456", "password", "qwerty", "letmein"]
user_password = "qwerty"

if user_password in common:
    print("This password is too common.")
````

if user_password not in common:

## Task 6: Loops: for and while


Python has two common types of loops:
- ``while loop``: Repeats as long as a condition is ``True``. Useful when the number of repetitions is unknown.
- ``for loop``: Iterates over items in a sequence, such as a list or string. Useful when processing a collection of items.


### Quick Recap: while Loops

A ``while loop`` repeats as long as its condition is ``True``.

````py
attempts = 0
max_attempts = 3

while attempts < max_attempts:
    password = input("Enter password: ")
    attempts += 1
    print(f"Attempt {attempts} of {max_attempts}")
````

### The for Loop

A ``for`` loop iterates through each item in a sequence, such as a list.
````py
targets = ["192.168.1.1", "192.168.1.2", "192.168.1.3"]

for ip in targets:
    print(f"Scanning {ip}...")
````

<img width="1371" height="195" alt="image" src="https://github.com/user-attachments/assets/b5a85bb7-8c13-4015-9aa5-ed87ac741706" />



- ``ip`` takes the value of each IP address, one at a time.
- The loop prints a message for each IP.
- The loop stops after processing all items.

- First iteration: ``ip = "192.168.1.1"``
- Second iteration: ``ip = "192.168.1.2"``
- Third iteration: ``ip = "192.168.1.3"``

> After processing all three IP addresses, the loop stops automatically.

### Iterating Over Strings

A string is also a sequence, so you can loop through it character by character. This is exactly what we need for tasks like password validation:

````py
password = "S3cure!"

for char in password:
    if char.isdigit():
        print(f"Found digit: {char}")
    elif char.isupper():
        print(f"Found uppercase: {char}")
````

### The range() Function

The ``range()`` function generates a sequence of numbers, allowing a ``for`` loop to repeat a specific number of times.

````py
# range(stop): 0 to stop-1
for i in range(5):
    print(i)       # prints 0, 1, 2, 3, 4

# range(start, stop): start to stop-1
for i in range(1, 6):
    print(i)       # prints 1, 2, 3, 4, 5

# range(start, stop, step): with custom increment
for i in range(0, 20, 5):
    print(i)       # prints 0, 5, 10, 15
````

In programming, counting often starts from 0. Consequently, ``range(5)`` produces five numbers: ``0``, ``1``, ``2``, ``3``, and ``4``.

### Iterating Over Dictionaries

### break and continue

Two keywords give you fine-grained control inside a loop:
- ``break`` immediately exits the loop entirely.
- ``continue`` skips the rest of the current iteration and moves to the next one.

````py
# Stop scanning as soon as we find port 443
for port in [22, 80, 443, 8080]:
    if port == 443:
        print(f"Port {port} found. Stopping scan.")
        break
    print(f"Checked port {port}")
````
<img width="1806" height="283" alt="image" src="https://github.com/user-attachments/assets/d0b642fa-0425-4627-8991-8a04be9f8c83" />


Notice that ``8080`` was never checked because ``break`` terminated the loop as soon as we found ``443``.

````py
# Skip blank lines when processing a file
lines = ["admin", "", "root", "", "guest"]

for line in lines:
    if line == "":
        continue       # skip empty strings
    print(f"Processing: {line}")
````
