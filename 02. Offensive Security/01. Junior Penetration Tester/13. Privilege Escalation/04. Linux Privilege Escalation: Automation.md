## Task 1: Introduction

| Topic                                      | Easy Explanation                                                                                       |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------ |
| **Linux Privilege Escalation: Automation** | Learn how to automate the process of finding Linux privilege escalation opportunities.                 |
| **Automated Enumeration**                  | Use tools to automatically check the system for useful privilege escalation weaknesses.                |
| **Public Exploits**                        | Learn how publicly available exploits can be used when a known vulnerability is found.                 |
| **Process Snooping**                       | Inspect running processes to find useful information or privileged processes you may be able to abuse. |
| **Main Purpose**                           | Make privilege escalation faster and find things that manual enumeration might miss.                   |


### Learning Objectives
- Demonstrate privilege escalation enumeration using automated tools
- Demonstrate privilege escalation techniques using public exploits
- Understand Linux process snooping
