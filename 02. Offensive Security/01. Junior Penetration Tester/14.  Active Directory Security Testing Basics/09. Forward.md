### Start Challenge

#### Set /etc/hosts

First in this I want to Set ``/etc/hosts``, cause the Kerberos steps need the DC hostname:
````
sudo nano /etc/hosts
````
Then input this:
````
10.49.135.181 dc01.ctf.local dc01 ctf.local
````





#### Initial Enumeration


##### Scan target with nmap
````
nmap -Pn -sC -sV -T4 10.49.135.181
````
<img width="1084" height="800" alt="image" src="https://github.com/user-attachments/assets/d8f164f1-850a-4879-8bbe-bf26790dab09" />


| Finding            | Meaning           |
| ------------------ | ----------------- |
| **IP**             | `10.49.135.181`   |
| **Hostname**       | `DC01.ctf.local`  |
| **Domain**         | `ctf.local`       |
| **NetBIOS Domain** | `CTF`             |
| **OS**             | Microsoft Windows |
| **Role**           | Domain Controller |
| **Kerberos**       | Port `88`         |
| **LDAP**           | Port `389`        |
| **SMB**            | Port `445`        |
| **RDP**            | Port `3389`       |
| **DNS**            | Port `53`         |


Also in this we see open port:
|       Port | Service              | What it tells you                 |
| ---------: | -------------------- | --------------------------------- |
|   `53/tcp` | DNS                  | Domain name resolution            |
|   `88/tcp` | Kerberos             | Active Directory authentication   |
|  `135/tcp` | MSRPC                | Windows RPC services              |
|  `139/tcp` | NetBIOS-SSN          | Windows/SMB-related communication |
|  `389/tcp` | LDAP                 | Query Active Directory            |
|  `445/tcp` | Microsoft-DS         | SMB file/network sharing          |
|  `464/tcp` | kpasswd              | Kerberos password changing        |
|  `593/tcp` | RPC over HTTP        | Windows RPC communication         |
|  `636/tcp` | LDAPS                | LDAP over TLS                     |
| `3268/tcp` | Global Catalog LDAP  | AD forest-wide directory searches |
| `3269/tcp` | Global Catalog LDAPS | Secure Global Catalog             |
| `3389/tcp` | RDP                  | Remote Desktop                    |



Or in this we can fiter on direct port:
````
nmap -Pn -sT -sV --version-light -p 53,88,135,139,389,445,464,593,636,3268,3269,3389,5985,9389 10.49.135.181
````

##### Test the supplied account:
````
nxc smb 10.49.135.181 -d ctf.local -u j.smith -p 'JSmith@IT2024'
````
<img width="1638" height="136" alt="image" src="https://github.com/user-attachments/assets/b30e434b-30fa-455b-9064-3db30e1dc628" />




Then in this I enumerate shares:
````
nxc smb 10.49.135.181 -u j.smith -p 'JSmith@IT2024' --shares
````
<img width="1607" height="261" alt="image" src="https://github.com/user-attachments/assets/ef0d6d3a-07d6-4582-8385-387aab9396d6" />


Now we see: 
| Share       | Permission | Meaning                                  |
| ----------- | ---------- | ---------------------------------------- |
| `ADMIN$`    | —          | Administrative share                     |
| `C$`        | —          | Entire system drive, normally admin-only |
| `Downloads` | **READ**   | File-drop share; worth checking          |
| `IPC$`      | —          | Remote IPC                               |
| `NETLOGON`  | **READ**   | Domain logon/scripts share               |
| `SYSVOL`    | **READ**   | AD Group Policy/scripts share            |


Then check next:
````
smbclient //10.49.135.181/Downloads -N
````
<img width="567" height="118" alt="image" src="https://github.com/user-attachments/assets/423b410f-f0ab-406a-bf9a-b009f0b25741" />
