**1. Reconnaissance & Enumeration**
- Network discovery and information gathering
- Port and service enumeration
- Nmap scanning techniques

**2. Web Application Security**
- HTTP request and response analysis
- Burp Suite
- Web application vulnerability testing
- OWASP Top 10

**3. Vulnerability Assessment & Exploitation**

- Password security testing

**4. System & Network Security**

- Privilege escalation
- Active Directory security testing

**5. Scripting & Reporting**
- Python scripting

## Learning Objectives

- Understand penetration testing fundamentals and methodologies.
- Develop network reconnaissance and enumeration skills.
- Identify and assess common web application vulnerabilities.
- Gain practical experience with penetration testing tools.
- Understand exploitation and privilege escalation techniques.
- Develop basic Active Directory security testing skills.
- Apply Python to security-related scripting and automation.
- Document findings using structured technical reports.

All practical exercises and techniques documented here are intended for educational purposes and authorized security testing within TryHackMe labs or other environments where explicit permission has been granted.

Never perform reconnaissance, scanning, exploitation, or security testing against systems without proper authorization.
