## Task 2: Extensions Interface

The ``Extensions interface`` lets we can manage and monitor extensions installed in Burp Suite.

<img width="1094" height="702" alt="image" src="https://github.com/user-attachments/assets/4bb1404f-38d3-4453-aa0e-d556c6541ad0" />


### 1. Extensions List
- The top section shows extensions installed in the current project.
- We can ``activate or deactivate`` extensions.

### 2. Managing Extensions
- **Add** → Install an extension from a file.
- **Remove** → Uninstall the selected extension.
- **Up / Down** → Change the order of extensions.
- The order matters because extensions are processed from top to bottom.

### 3. Details, Output, and Errors
- **Details* → Shows information about the selected extension.
- **Output** → Shows output/results produced by the extension.
- **Errors** → Shows errors that occurred while the extension was running.

### Question & Answer:

#### 1. Are extensions invoked in ascending (A) or descending (D) order?
````
D
````


##### Why?
Because Burp processes extensions from the top of the list downward.

````
Top extension
     ↓
Second extension
     ↓
Third extension
     ↓
Bottom extension
````
This is called **descending order (D)**.

## Task 3: BApp Store

App Store = Burp Suite's extension store.

- We can find and install extensions directly from Burp.
- Extensions are commonly written in Java or Python.
- ``Java`` → integrates directly with Burp.
- ``Python`` → requires Jython.

BApp Store lets you find and install official Burp Suite extensions.

1. Open BApp Store
- Go to ``Extensions`` → ``BApp Store``.

2. Search for the extension
- Search for ``Request Timer``.
- There should be one result.

3. Select Request Timer
- Click the extension to view its details.

4. Install
- Click ``Install`` to add it to Burp Suite.



### Request Timer

The Request Timer extension measures how long requests take to receive a response.

It can be useful for identifying time-based differences, such as when valid and invalid inputs produce different response times.
