### Welcome to the Burp Suite Intruder room!
| Topic                    | Short Explanation                                                 |
| ------------------------ | ----------------------------------------------------------------- |
| **Room**                 | Burp Suite Intruder                                               |
| **Purpose**              | Learn how to automate and customize HTTP requests                 |
| **Intruder**             | Burp tool for sending many requests with different input values   |
| **Fuzzing**              | Test many different inputs against an application                 |
| **Brute-force**          | Automatically try many possible values, such as passwords         |
| **Request Manipulation** | Change specific parts of a request automatically                  |
| **Prerequisite**         | Basic knowledge of **Burp Proxy** and **Repeater** is recommended |
| **Lab Machine**          | Click **Start Lab Machine**                                       |
| **AttackBox**            | Start it if you're not using your own Kali/VM                     |
| **Next Step**            | Start Burp Suite and continue with the Intruder tasks             |
