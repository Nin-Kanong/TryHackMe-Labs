## Task 2: Service Detection

After Nmap finds an open port, ``-sV`` helps identify what service and version is actually running.

### Command Syntax:
````
sudo nmap -sV TARGET
````


Example:
````
sudo nmap -sV 10.48.137.93
````
<img width="1002" height="442" alt="image" src="https://github.com/user-attachments/assets/5b64f343-509f-4f95-af42-36f299dbd964" />


#### Version Detection Intensity
| Command                 | Meaning                      |
| ----------------------- | ---------------------------- |
| `-sV`                   | Detect services and versions |
| `--version-light`       | Faster, less probing         |
| `--version-intensity 2` | Low intensity                |
| `--version-intensity 9` | Highest intensity            |
| `--version-all`         | Try all version probes       |


Example:
````
sudo nmap -sV --version-light 10.48.137.93
````
<img width="1025" height="448" alt="image" src="https://github.com/user-attachments/assets/8900960b-3ed3-4eb7-b0e2-8748c00292ed" />


> **Note**: ``-sV`` performs service/version detection and normally requires completing a TCP connection, so it is different from a SYN stealth scan (-sS).

## Task 3: OS Detection & Traceroute

### 1. OS Detection

Nmap can try to identify the target's operating system.

#### Syntax:
````
sudo nmap -sS -O TARGET
````


Example:
````
sudo nmap -sS -O 10.48.137.93
````
<img width="1061" height="710" alt="image" src="https://github.com/user-attachments/assets/0ddb21a5-14ae-40d8-a875-b01b8497d455" />


| Option | Meaning      |
| ------ | ------------ |
| `-sS`  | TCP SYN scan |
| `-O`   | OS detection |


> Nmap examines things such as **TTL**, **TCP behavior, and packet responses**.

#### Flow:
````
Target
  ↓
-O
  ↓
Analyze network behavior
  ↓
OS fingerprint
  ↓
Possible Linux / Windows / etc.
````

> **Note**: OS detection is not always 100% accurate, especially with virtualization, firewalls, cloud networking, or modified TCP behavior.




### 2. Traceroute

Traceroute shows the network path/hops between you and the target.

Use:
````
sudo nmap -sS --traceroute TARGET
````

Example:
````
sudo nmap -sS --traceroute 10.48.137.93
````
<img width="877" height="482" alt="image" src="https://github.com/user-attachments/assets/4ff7e10b-3198-46d9-b26f-10e5f038e7ab" />


| Part           | Meaning                       |
| -------------- | ----------------------------- |
| `--traceroute` | Perform traceroute            |
| `HOP`          | Router/network hop number     |
| `RTT`          | Round-trip time               |
| `ADDRESS`      | Address of the discovered hop |



#### Flow:
````
Your PC
   ↓
Router 1
   ↓
Router 2
   ↓
Router 3
   ↓
Target
````

## Task 4: Nmap Scripting Engine (NSE)

NSE lets Nmap run Lua scripts to collect extra information about a target.

Source: https://nmap.org/book/man-nse.html

### Basic commands
| Command               | Meaning                        |
| --------------------- | ------------------------------ |
| `-sC`                 | Run default NSE scripts        |
| `--script-default`    | Same as default scripts        |
| `--script NAME`       | Run a specific script          |
| `--script "PATTERN*"` | Run scripts matching a pattern |

#### Script location
````
/usr/share/nmap/scripts/
````

````
ls /usr/share/nmap/scripts/
````
<img width="1086" height="1033" alt="image" src="https://github.com/user-attachments/assets/646b5034-dca5-470a-9cfc-e45bd2951ee7" />


#### List HTTP scripts:
````
ls /usr/share/nmap/scripts/http*
````
<img width="1823" height="909" alt="image" src="https://github.com/user-attachments/assets/356dcaca-e767-4d46-aaa4-81be8eea532c" />



#### Default scripts
````
sudo nmap -sS -sC 10.48.137.93
````
<img width="1213" height="822" alt="image" src="https://github.com/user-attachments/assets/50a8db7a-a3ad-4672-89f6-d7320c25c422" />


- ``-sC`` runs Nmap's default script category.

#### Script categories
| Category    | Easy meaning                |
| ----------- | --------------------------- |
| `auth`      | Authentication checks       |
| `broadcast` | Discover hosts              |
| `brute`     | Password auditing           |
| `default`   | Default scripts             |
| `discovery` | Gather information          |
| `dos`       | DoS vulnerability checks    |
| `exploit`   | Exploit checks              |
| `external`  | Third-party services        |
| `fuzzer`    | Fuzzing                     |
| `intrusive` | More aggressive scripts     |
| `malware`   | Backdoor detection          |
| `safe`      | Safer scripts               |
| `version`   | Service/version information |
| `vuln`      | Vulnerability checks        |

### 3. XML output — -oX

Useful when another program needs to process the Nmap results.
````
sudo nmap -sV 10.48.137.93 -oX scan.xml
````

### 4. Save all three formats

Use:
````
sudo nmap -sV 10.48.137.93 -oA scan
````

### Summary:

| Option | Format            | Example          |
| ------ | ----------------- | ---------------- |
| `-oN`  | Normal            | `-oN scan.txt`   |
| `-oG`  | Grepable          | `-oG scan.gnmap` |
| `-oX`  | XML               | `-oX scan.xml`   |
| `-oA`  | All 3             | `-oA scan`       |
| `-O`   | OS detection      | `-O`             |
| `-sV`  | Version detection | `-sV`            |

## Task 6: Summary

| Option                | Meaning                            |
| --------------------- | ---------------------------------- |
| `-sV`                 | Detect service/version information |
| `-sV --version-light` | Use fewer probes                   |
| `-sV --version-all`   | Use all probes                     |
| `-O`                  | Detect operating system            |
| `--traceroute`        | Trace network path                 |
| `--script <SCRIPTS>`  | Run NSE scripts                    |
| `-sC`                 | Run default NSE scripts            |
| `-A`                  | `-sV + -O + -sC + --traceroute`    |
| `-oN`                 | Save normal output                 |
| `-oG`                 | Save grepable output               |
| `-oX`                 | Save XML output                    |
| `-oA`                 | Save **normal + grepable + XML**   |
