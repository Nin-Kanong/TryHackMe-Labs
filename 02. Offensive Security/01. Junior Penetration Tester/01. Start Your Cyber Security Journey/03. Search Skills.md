## Task 4: Vulnerability Databases (CVE)


- **CVE (Common Vulnerabilities and Exposures)** = the industry's universal dictionary of known vulnerabilities — every confirmed vuln gets a unique ID so everyone refers to the same issue.
- ID format: ``CVE-YEAR-NUMBER``, e.g. ``CVE-2025-55182`` (the React Server Components RCE shown in the NIST/NVD screenshot).

Famous CVEs get ``nicknames``: Heartbleed, Log4Shell, React2Shell.


#### CVSS scoring (how bad is it?)

| Factor              | Question It Answers                      |
| ------------------- | ---------------------------------------- |
| 💥 **Impact**       | What damage can the vulnerability cause? |
| 🧩 **Complexity**   | How easy is it to exploit?               |
| 🎯 **Availability** | How likely is exploitation to happen?    |

- Scores run ``0–10``; the example CVE scores ``10.0 CRITICAL`` (network-exploitable, low complexity, no privileges needed, full CIA impact).
Organizations patch ``highest score first`` to prioritize risk.


#### Where to look them up
| Platform           | Purpose                                                                                                   |
| ------------------ | --------------------------------------------------------------------------------------------------------- |
| 🛡️ **NVD (NIST)** | Official vulnerability details + **CVSS severity scores** for CVEs                                        |
| 💥 **Exploit-DB**  | Lists vulnerabilities alongside available **PoCs (Proof-of-Concept exploits)** such as SQLi, RCE, and XSS |

## Task 5: Technical Documentation (MAN)

- **Official tool docs** are the most reliable, up‑to‑date source — make them your first stop, not your last, when learning or troubleshooting a tool.
- **Linux man pages** = built‑in terminal documentation for any command.

Usage:
````
man <command>      # e.g. man nc
````

Example:
````
man nc
````
<img width="327" height="94" alt="image" src="https://github.com/user-attachments/assets/30b12836-7437-4809-9c35-2181846696c5" />

<img width="1919" height="1079" alt="image" src="https://github.com/user-attachments/assets/dee4915f-4bfd-48c7-be6d-87cbc2a98cbc" />

Press `q` to exit.

isplays NAME (``nc`` – ``arbitrary TCP and UDP connections and listens``) and SYNOPSIS (all flags/usage).

##### Navigating a man page
| Key     | Action                                  |
| ------- | --------------------------------------- |
| `Space` | Page **down**                           |
| `b`     | Page **up**                             |
| `/text` | Search **forward** for text, e.g. `/-e` |
| `n`     | Go to **next match**                    |
| `q`     | **Quit**                                |


##### search man pages by keyword (apropos)
````
man -k netcat
````

##### quick flag summary
````
nc --help
````
