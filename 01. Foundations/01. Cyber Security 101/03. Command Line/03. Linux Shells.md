## Task 1 – Introduction to Linux Shells

### What is a Linux Shell?
A **Linux** shell is a command-line interpreter that allows users to interact with the operating system (OS) by typing commands instead of using a graphical interface (GUI).

### GUI vs CLI
| GUI (Graphical User Interface) | CLI (Command Line Interface)       |
| ------------------------------ | ---------------------------------- |
| Uses windows, icons, and menus | Uses text commands                 |
| Easy for beginners             | Faster and more powerful           |
| Requires more system resources | Lightweight and resource-efficient |
| Mouse-driven                   | Keyboard-driven                    |


### Restaurant Analogy

| GUI                                                | CLI                                             |
| -------------------------------------------------- | ----------------------------------------------- |
| Order food from the menu and the waiter serves it. | Go into the kitchen and cook the food yourself. |

- ``Kitchen`` = Operating System (OS)
- ``Waiter`` = GUI
- ``Cooking our`` = CLI (Shell)

The CLI gives you more control and flexibility over the system.




### Why Use the Linux Shell?
- Faster than using the GUI
- Uses fewer system resources
- Gives full control over the OS
- Supports automation through scripts
- Preferred by system administrators, developers, and cybersecurity professionals


### Learning Objectives
- Interact with the Linux shell
- Learn basic shell commands
- Explore different Linux shells
- Write basic shell scripts

### 9. Comments
Comments make scripts easier to understand.
````
# This is a comment
````
Example:
````
# Defining the Interpreter
#!/bin/bash

# Asking the user to enter a value.
echo "Please enter your name first:"

# Storing the user input value in a variable.
read name

# Checking if the name the user entered is equal to our required name.
if [ "$name" = "Stewart" ]; then

# If it equals the required name, the following line will be displayed.
echo "Welcome Stewart! Here is the secret: THM_Script"

# Defining the sentence to be displayed if the condition fails.
else
        echo "Sorry! You are not authorized to access the secret."
fi
````
Comments are ignored during execution.

## Task 5 — The Locker Script

This task combines everything you've learned:
- Variables
- Loops
- Conditional Statements
- User Input



### Script:
````
#!/bin/bash
# Shebang
# Tells Linux to execute this script using the Bash interpreter.

# ============================
# Variables
# ============================

username=""
# Variable to store the username entered by the user.

companyname=""
# Variable to store the company name.

pin=""
# Variable to store the PIN.

# ============================
# Loop
# ============================

for i in {1..3}; do
# for loop repeats 3 times.
# i = 1, then 2, then 3.

    # ============================
    # Conditional Statements
    # ============================

    if [ "$i" -eq 1 ]; then
    # -eq means "Equal To".
    # If i equals 1, ask for Username.

        echo "Enter your Username:"
        # Display a message.

        read username
        # Read user input and store it in the variable "username".

    elif [ "$i" -eq 2 ]; then
    # elif means "Else If".
    # If i equals 2, ask for Company name.

        echo "Enter your Company name:"
        # Display message.

        read companyname
        # Store company name entered by the user.

    else
    # Runs when i is not 1 or 2.
    # Since the loop runs 1..3, this means i = 3.

        echo "Enter your PIN:"
        # Display message.

        read pin
        # Store PIN entered by the user.

    fi
    # End of the if-elif-else statement.

done
# End of the for loop.

# ============================
# Authentication
# ============================

if [ "$username" = "John" ] && \
   [ "$companyname" = "Tryhackme" ] && \
   [ "$pin" = "7385" ]; then

# "=" compares strings.
# "&&" means AND.
# All three conditions must be TRUE.

    echo "Authentication Successful. You can now access your locker, John."
    # Display success message.

else
    # Runs if any one of the conditions is false.

    echo "Authentication Denied!!"
    # Display failure message.

fi
# End of the authentication if statement.
````
