### What is PowerShell?
**PowerShell** is Microsoft's powerful command-line shell and scripting language used to manage Windows systems.

Unlike Command Prompt (CMD), PowerShell can:
- Manage Windows
- Automate tasks
- Control services
- Work with files
- Query system information
- Write automation scripts

### Learning Objectives
| Objective                | Description                                                                          |
| ------------------------ | ------------------------------------------------------------------------------------ |
| Learn PowerShell         | Understand what PowerShell is and what it can do.                                    |
| Learn PowerShell syntax  | Understand how PowerShell commands are written.                                      |
| Learn basic commands     | Use common PowerShell commands for everyday tasks.                                   |
| Learn cybersecurity uses | Discover how PowerShell is used by system administrators and security professionals. |


### Why Learn PowerShell?
| Benefit               | Example                                                               |
| --------------------- | --------------------------------------------------------------------- |
| System Administration | Manage Windows computers remotely                                     |
| Automation            | Run repetitive tasks automatically                                    |
| Information Gathering | View processes, services, users, and network settings                 |
| Active Directory      | Manage users, groups, and computers                                   |
| Cybersecurity         | Enumeration, incident response, digital forensics, and administration |


### CMD vs PowerShell
| Command Prompt (CMD) | PowerShell                      |
| -------------------- | ------------------------------- |
| Basic commands       | Advanced commands               |
| Limited scripting    | Powerful scripting language     |
| Text output          | Objects as output               |
| Older Windows shell  | Modern Windows management shell |

## What is PowerShell?



### What is PowerShell?

<img width="412" height="238" alt="image" src="https://github.com/user-attachments/assets/883f3265-9871-4872-82d6-d106c07428e6" />

**PowerShell* is a command-line shell and scripting language created by Microsoft to automate tasks and manage Windows systems.

It is much more powerful than Command Prompt (CMD).


### What Can PowerShell Do?
| Feature                  | Description                                    |
| ------------------------ | ---------------------------------------------- |
| Command-line Shell       | Run commands to manage Windows.                |
| Scripting Language       | Create scripts (`.ps1`) to automate tasks.     |
| Configuration Management | Configure and manage computers.                |
| Cross-Platform           | Runs on **Windows**, **Linux**, and **macOS**. |


### Brief History
| Year        | Event                                                                             |
| ----------- | --------------------------------------------------------------------------------- |
| Early 2000s | Microsoft created PowerShell to replace the limitations of CMD and batch scripts. |
| 2006        | First release of Windows PowerShell.                                              |
| 2016        | PowerShell Core released as open source for Windows, Linux, and macOS.            |

- ``Jeffrey Snover``, a Microsoft engineer, realised that Windows and Unix handled system operations differently—Windows used structured data and APIs, while Unix treated everything as text files. 

### Why PowerShell is Powerful
Unlike CMD, which outputs plain text, PowerShell works with objects.

#### CMD
Check IP:
````
ipconfig
````

#### PowerShell
````
Get-Process
````
Each process contains useful information like:
- Name
- ID (PID)
- CPU
- Memory
- Status


### What is an Object?
| Part           | Description                    | Example                  |
| -------------- | ------------------------------ | ------------------------ |
| **Properties** | Information about the object   | Name, Model, Color       |
| **Methods**    | Actions the object can perform | Start(), Stop(), Drive() |

Example: A car object
| Properties | Methods    |
| ---------- | ---------- |
| Color      | Drive()    |
| Model      | HonkHorn() |
| FuelLevel  | Refuel()   |

## Task 5 – Piping, Filtering, and Sorting Data


### Windows PowerShell Pigin

| **Topic**             | **Cmdlet / Syntax** | **Purpose**                                           | **Example**                                              | **Equivalent (CMD/Linux)** |
| --------------------- | ------------------- | ----------------------------------------------------- | -------------------------------------------------------- | -------------------------- |
| **Pipeline**          | `\|`                | Passes the output (objects) of one cmdlet to another. | `Get-ChildItem \| Sort-Object Length`                    | `\|`                       |
| **List Files**        | `Get-ChildItem`     | Lists files and folders in a directory.               | `Get-ChildItem`                                          | `dir` / `ls`               |
| **Sort Objects**      | `Sort-Object`       | Sorts objects by a property.                          | `Get-ChildItem \| Sort-Object Length`                    | `sort`                     |
| **Filter Objects**    | `Where-Object`      | Filters objects based on conditions.                  | `Get-ChildItem \| Where-Object Extension -eq ".txt"`     | `find`, `grep` (partial)   |
| **Select Properties** | `Select-Object`     | Displays only selected properties.                    | `Get-ChildItem \| Select-Object Name,Length`             | N/A                        |
| **Search Text**       | `Select-String`     | Searches text inside files (supports regex).          | `Select-String -Path ".\captain-hat.txt" -Pattern "hat"` | `grep` / `findstr`         |


### 1. Pipeline (|)
The pipeline sends the output of one cmdlet directly into another.

````
Get-ChildItem | Sort-Object Length
````
<img width="750" height="415" alt="image" src="https://github.com/user-attachments/assets/cae62e66-4d41-400a-9c34-bad1c4571177" />


| Part            | Explanation                                            |
| --------------- | ------------------------------------------------------ |
| `Get-ChildItem` | Lists files and folders in the current directory.      |

### What is Scripting?
**Scripting** is the process of writing and executing a series of commands stored in a text file (called a script) to automate repetitive tasks.

Instead of typing commands one by one:
````
Command 1
Command 2
Command 3
````
We write them once:
````
script.ps1
````
Then execute:
````
.\script.ps1
````


### Why Use Scripts?
| Benefit       | Description                               |
| ------------- | ----------------------------------------- |
| Automation    | Perform repetitive tasks automatically    |
| Save Time     | Execute many commands with one command    |
| Reduce Errors | Avoid typing mistakes                     |
| Consistency   | Every execution performs the same actions |
| Scalability   | Manage hundreds of systems simultaneously |

## Summary

* **PowerShell** is Microsoft's command-line shell and scripting language built on the **.NET Framework**.
* Uses **objects** instead of plain text, making data easier to filter and manipulate.
* **Cmdlets** follow the **Verb-Noun** format (e.g., `Get-Process`, `Set-Location`).
* Use **`Get-Command`** to list cmdlets and **`Get-Help`** to view documentation and examples.
* Manage files with cmdlets like **`Get-ChildItem`**, **`Set-Location`**, **`New-Item`**, **`Copy-Item`**, **`Move-Item`**, **`Remove-Item`**, and **`Get-Content`**.
* Filter and process data using the **pipeline (`|`)**, **`Where-Object`**, **`Sort-Object`**, **`Select-Object`**, and **`Select-String`**.
* Gather system information with **`Get-ComputerInfo`**, **`Get-LocalUser`**, **`Get-NetIPConfiguration`**, and **`Get-NetIPAddress`**.
* Monitor processes, services, and connections using **`Get-Process`**, **`Get-Service`**, and **`Get-NetTCPConnection`**.
* Verify file integrity with **`Get-FileHash`** and inspect **Alternate Data Streams (ADS)** using **`Get-Item -Stream *`**.
* Automate tasks with **PowerShell scripts (`.ps1`)** and execute commands on remote systems using **`Invoke-Command`** (requires **PowerShell Remoting/WinRM**).

### Key Takeaway

PowerShell is a powerful automation and administration tool that helps manage Windows systems, analyze data, automate repetitive tasks, and perform system administration and cybersecurity operations efficiently.
