### Lab challeng:

Oooh, turns out, this 10.49.186.81 machine is also a `DNS` server! If we could ``dig`` into it, I am sure we could find some interesting records! But... it seems weird, this only responds to a special type of request for a ``givemetheflag.com`` domain?


**Access this challenge** by deploying both the vulnerable machine by pressing the green "Start Lab Machine" button located within this task, and the TryHackMe AttackBox by pressing the  "Start AttackBox" button located at the top-right of the page.


Use some common `DNS` enumeration tools installed on the AttackBox to get the `DNS` server on ``10.49.186.81`` to respond with the flag.

#### Scan with nmap:
````
nmap -sV -sC -T4 10.49.186.81
````

<img width="1167" height="400" alt="image" src="https://github.com/user-attachments/assets/3bdb7b1e-a0e6-44ff-8548-3df0c1a0ee90" />


Now we see only one open port.


After enumeration is:
````
dig @10.49.186.81 givemetheflag.com
````
<img width="1102" height="498" alt="image" src="https://github.com/user-attachments/assets/f398a962-1535-46f3-af06-0db14113f7e2" />


Now we see the correct flag.


Or we can use others command:
|  # | Command                                     | Record Type | Purpose                                      |
| -: | ------------------------------------------- | :---------: | -------------------------------------------- |
|  1 | `dig @10.49.186.81 givemetheflag.com A`     |    **A**    | Maps domain → IPv4 address                   |
|  2 | `dig @10.49.186.81 givemetheflag.com AAAA`  |   **AAAA**  | Maps domain → IPv6 address                   |
|  3 | `dig @10.49.186.81 givemetheflag.com NS`    |    **NS**   | Lists authoritative name servers             |
|  4 | `dig @10.49.186.81 givemetheflag.com MX`    |    **MX**   | Lists mail servers                           |
|  5 | `dig @10.49.186.81 givemetheflag.com CNAME` |  **CNAME**  | Shows aliases / canonical names              |
|  6 | `dig @10.49.186.81 givemetheflag.com SOA`   |   **SOA**   | Shows Start of Authority / zone information  |
|  7 | `dig @10.49.186.81 givemetheflag.com TXT`   |   **TXT**   | ⭐ Text records → **returns the flag**        |
|  8 | `dig @10.49.186.81 givemetheflag.com ANY`   |   **ANY**   | Requests multiple/all available record types |
|  9 | `dig @10.49.186.81 givemetheflag.com AXFR`  |   **AXFR**  | Attempts a full DNS zone transfer            |
