## Task 1: Introduction

### 1. What is Burp Suite?
**Burp Suite is a web application security testing framework used by penetration testers and security professionals to analyze and test websites.

| **Installation**            | Install Burp Suite                    |
| **Navigation**              | Understand the interface              |
| **Configuration**           | Configure Burp for testing            |
