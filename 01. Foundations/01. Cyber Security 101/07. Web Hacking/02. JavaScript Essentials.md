## Essential Concepts

### 1. VARIABLES

Three ways to declare variables:
| **Keyword** | **Scope**       | **Use When**                                 |
| ----------- | --------------- | -------------------------------------------- |
| `var`       | Function-scoped | Older code (avoid in modern JavaScript)      |
| `let`       | Block-scoped    | When the value will change                   |
| `const`     | Block-scoped    | When the value won't change (default choice) |

Use ``const`` by default, ``let`` when you need reassignment, avoid ``var``.


### 2. DATA TYPES

Primitive Types:
- **string**: text (``"hello"``)
- **number**: integers/decimals (``42``, ``3.14``)
- **boolean**: ``true`` or ``false``
- **null**: intentional empty value
- **undefined**: variable declared but not assigned
- **object**: complex data (arrays, objects)

// Creates a function named PrintResult.
// The function accepts one parameter called rollNum.
function PrintResult(rollNum) {

  alert("Username with roll number " + rollNum + " has passed the exam");

// const creates a constant variable.

const rollNumbers = [101, 102, 103];

// Array contents:
//
// Index    Value
// -----    -----
// 0        101
// 1        102
// 2        103

// rollNumbers.length = 3

// ================================
// Loop Through the Array
// ================================

// Start i at 0.
// Continue while i is less than the array length.
// Increase i by 1 after every iteration.

for (let i = 0; i < rollNumbers.length; i++) {
  // Current array element
  let currentRollNumber = rollNumbers[i];

  // Pass the roll number to the function.
  PrintResult(currentRollNumber);
}

### 3. Loops


Repeat code while a condition is true
| Loop Type      | When to Use                                              |
| -------------- | -------------------------------------------------------- |
| **for**        | When you know how many times to loop                     |
| **while**      | When the loop count is unknown                           |
| **do...while** | Execute the code at least once, then check the condition |

````
// Function to print student result
function PrintResult(rollNum) {
    alert("Username with roll number " + rollNum + " has passed the exam");
}

// Prepare an array of roll numbers
const rollNumbers = [101, 102, 103];

// Loop through the array
for (let i = 0; i < rollNumbers.length; i++) {
    PrintResult(rollNumbers[i]);
}
````

## Task 3: Javascript Overview

JavaScript (JS) is an interpreted language (runs directly in the browser, no compilation needed).

JS code can:
- Create variables to store data.
- Use data types (number, string, boolean, etc.).
- Make decisions with control flow (if, else, switch).
- Repeat actions with loops.
- Organize code into functions for reuse.

These are the basic building blocks for creating interactive web applications.

````
// Hello, World! program
console.log("Hello, World!");

// Variable and Data Type
let age = 25; // Number type

// Control Flow Statement
if (age >= 18) {
    console.log("You are an adult.");
} else {
    console.log("You are a minor.");
}

// Function
function greet(name) {
    console.log("Hello, " + name + "!");
}

// Calling the function
greet("Bob");
````

#### Explaination:

Summary:

- ``=`` → Assign a value.
- ``+`` → Add numbers or join text.
- ``console.log()`` → Display output in the console.

## Task 4: Integrating JavaScript in HTML

- JavaScript (JS) works with HTML and CSS to make web pages dynamic and interactive.
- JS is not used to create page content—HTML does that. JS adds behavior and interactivity.
- There are 2 ways to add JavaScript to HTML:
  - Internal JavaScript – write JS inside the HTML file using the ``<script>`` tag.
  - External JavaScript – write JS in a separate ``.js`` file and link it to the HTML file.


Internal JavaScript
JS code is written inside the HTML file.
Use the ``<script>`` tag.
The ``<script>`` tag can be placed:
Inside the ``<head>`` section (runs before page content loads).
Inside the ``<body>`` section (commonly placed near the end to interact with page elements).

````
<!DOCTYPE html>
<html>
<head>
    <title>Internal JavaScript</title>
</head>
<body>

    <h1>Hello JavaScript</h1>

    <script>
        console.log("Hello, World!");
    </script>

</body>
</html>
````
| Method          | Description                                   |
| --------------- | --------------------------------------------- |
| **Internal JS** | JS code inside the HTML file using `<script>` |
| **External JS** | JS code stored in a separate `.js` file       |
