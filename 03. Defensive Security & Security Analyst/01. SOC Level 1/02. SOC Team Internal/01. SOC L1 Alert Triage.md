## Task 1: Introduction

A security alert is a notification about suspicious activity or a possible security threat.

#### Main SOC L1 Responsibilities

1. **Receive**: Get alerts from security tools (SIEM, EDR).
2. **Analyse**: Check logs and investigate suspicious activity.
3. **Validate**: Determine whether it is a real threat or a false positive.
4. **Escalate**: Send complex incidents to senior analysts.
5. **Resolve**: Close the alert after appropriate action.

> A SOC L1 Analyst must detect, investigate, and correctly handle alerts to prevent security breaches.

## Task 2: Event and Alerts

A **security alert** is a notification generated when a security tool detects suspicious or potentially malicious activity.

**Example:**
- **Email Marked as Phishing**: A suspicious email is detected.
- **Unusual Gmail Login Location**: A login occurs from an unusual location.
- **Unapproved Mimikatz Usage**: A tool commonly used to extract Windows credentials is detected.

> SOC analysts must understand, investigate, and respond to alerts to prevent security breaches.

---


### From Events to Alerts

An event is any activity happening on a system, such as a login, process launch, or file download.

#### How Events Become Alerts

Key Difference:
- **Event**: Any activity happening on a system.
- **Log**: A record of that activity.
- **Alert**: A notification about suspicious activity that needs investigation.


#### Alert Management Platforms 

These platforms help SOC teams collect, manage, and investigate security alerts.

| Platform  | Purpose                                              | Examples                        |
| --------- | ---------------------------------------------------- | ------------------------------- |
| SIEM      | Collects logs and manages security alerts.           | Splunk ES, Elastic              |
| EDR / NDR | Detects threats on endpoints and networks.           | Microsoft Defender, CrowdStrike |
| SOAR      | Centralises alerts and automates security responses. | Splunk SOAR, Cortex SOAR        |
| ITSM      | Manages security tickets and tasks.                  | Jira, TheHive                   |

### L1 Role in Alert Triage

Alert Triage means reviewing security alerts to decide whether they are real threats or false positives.

#### SOC Team Responsibilities

| Role         | Responsibility                                   |
| ------------ | ------------------------------------------------ |
| SOC L1       | Reviews alerts and escalates real threats to L2. |
| SOC L2       | Performs deeper investigation and remediation.   |
| SOC Engineer | Ensures alerts contain useful information.       |
| SOC Manager  | Monitors alert handling speed and quality.       |

> L1 detects and filters alerts, L2 investigates deeper, engineers maintain tools, and managers oversee the process.
